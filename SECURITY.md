# Security policy

## Supported versions

Only the latest released version gets fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through [GitHub Security Advisories](https://github.com/jbrulmans/conventional-comments-vscode/security/advisories/new) instead. You'll get a response within a week.

For context: the extension only edits the text of the comment box you're typing in. It doesn't read workspace files, run processes, or make network requests. Badge images are loaded from shields.io by whatever renders the comment, e.g. GitHub.
